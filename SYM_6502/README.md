# SYM-1 semi replica

## Introduction

The SYM-1 was a single-board computer released in 1975 by Synertek Systems. I learned to program in assembler on this SBC. This repository is a tribute to this old SBC.
This project is not a faithful reproduction of the SYM-1, for example it uses a SD card (stolen from the Alius project), and it has many electrical bugs including two or three which are really stupid. Yet it has zero KiCad errors and warnings. Consider it as a placeholder for a future version, some kind of alpha version.
